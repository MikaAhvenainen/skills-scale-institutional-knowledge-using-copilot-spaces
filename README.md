# OctoAcme Project Management Docs

This repository contains the project management processes and supporting guidance used by OctoAcme.

## Process Summary

OctoAcme follows a lightweight project lifecycle: initiation, planning, execution, release, and retrospective. We align stakeholders early, define success metrics and milestones, manage risks and dependencies, track execution with clear communication, and use retrospectives to improve continuously.

## Lifecycle Overview

1. Initiation — validate the problem, align stakeholders, and define the project one-pager.
2. Planning — create a backlog, estimate work, define milestones, and clarify responsibilities.
3. Execution — manage day-to-day delivery, track progress, and escalate blockers when needed.
4. Release — validate readiness, deploy changes, and communicate outcomes to stakeholders.
5. Retrospective — capture lessons learned and convert them into action items for continuous improvement.

## Core Team Roles

- Project Manager (PM): coordinates delivery, schedules, risk, and communications.
- Product Manager / Product Lead: defines outcomes, priorities, and success criteria.
- Developers: design, build, and validate implementation.
- QA / Testing: confirm quality and acceptance criteria.
- Stakeholders: provide input, direction, and approvals.
